# Azure DevOps Learning Rules

## Rule 1

Understand first.
Never memorize.

---

## Rule 2

Everything must be implemented on our AI TaskManager MultiTenant project.

---

## Rule 3

Every concept must answer:

- What is it?
- Why is it used?
- What problem does it solve?
- Where is it used?
- How does it work internally?

---

## Rule 4

Every module must contain:

- Theory
- Practical
- Interview Questions
- Best Practices
- Common Mistakes
- Summary
- Assignment

---

## Rule 5

Every practical must be completed.

Watching videos is not enough.

---

## Rule 6

Every Azure DevOps feature must be explained using our own project.

---

## Rule 7

Never copy notes from the internet.

Understand first.

Write in your own words.

---

## Rule 8

If something fails,

Debug it.

Do not skip it.

Debugging is learning.

---

## Rule 9

Keep every note simple.

If I cannot explain it simply,

I don't understand it yet.

---

## Rule 10

The goal is not certification.

The goal is becoming a professional Azure DevOps Engineer.
