# Module 01 – Interview Questions

---

## Q1. What is DevOps?

### Answer

DevOps is a culture and a set of practices that bring the Development and Operations teams together. It helps automate the process of building, testing, deploying, and maintaining software.

The main goal of DevOps is to deliver software faster, with fewer errors, and better collaboration between teams.

**Simple Definition:**

> DevOps = Development + Operations + Automation

---

## Q2. What is the difference between DevOps and Agile?

### Answer

| Agile |                                    | DevOps |
| Focuses on developing software faster            | Focuses on delivering and maintaining software faster |
| Mainly used by the Development team              | Used by both Development and Operations teams |
| Improves the software development process        | Improves the complete software delivery process |
| Ends after the software is developed             | Continues until the software is deployed and monitored |

**Simple Explanation:**

- Agile helps developers write software quickly.
- DevOps helps deliver that software to users quickly and safely.

---

## Q3. Is DevOps a tool?

### Answer

No.

DevOps is **not** a tool.

It is a **culture**, **mindset**, and **set of practices** that encourage collaboration between Development and Operations teams.

Many tools support DevOps, such as:

- Azure DevOps
- GitHub
- GitLab
- Jenkins
- Docker
- Kubernetes

These tools help implement DevOps practices, but they are **not DevOps**.

---

## Q4. Why is DevOps important?

### Answer

DevOps is important because it helps companies:

- Deliver software faster
- Reduce manual work
- Improve collaboration
- Reduce deployment errors
- Automate testing and deployment
- Improve software quality
- Release updates more frequently

## Q7. What is Azure DevOps?

### Answer

Azure DevOps is Microsoft's cloud platform that helps teams plan, develop, build, test, and deploy software.

It provides services such as:

- Azure Boards
- Azure Repos
- Azure Pipelines
- Azure Test Plans
- Azure Artifacts

Azure DevOps is a tool that helps teams follow DevOps practices.

---

## Q8. What are the services available in Azure DevOps?

### Answer

Azure DevOps provides five main services:

| Service | Purpose |
|----------|----------|
| Azure Boards | Project planning and work tracking |
| Azure Repos | Git source code management |
| Azure Pipelines | Build, test, and deployment automation |
| Azure Test Plans | Manual and exploratory testing |
| Azure Artifacts | Package management |

---

## Q9. Can DevOps be implemented without Azure DevOps?

### Answer

Yes.

DevOps is a culture, not a tool.

Many tools can be used to implement DevOps, such as:

- GitHub
- Jenkins
- GitLab
- Docker
- Kubernetes
- CircleCI

Azure DevOps is just one platform among many.

---

## Q10. Give a real-world example of DevOps.

### Answer

In our AI TaskManager MultiTenant project:

Without DevOps:

- Build the application manually.
- Create a ZIP file.
- Send it to the Operations team.
- Operations deploys it manually.

With DevOps:

- Push code to GitHub.
- Pipeline starts automatically.
- Build the application.
- Run unit tests.
- Create Docker images.
- Deploy automatically.

This reduces manual work, saves time, and minimizes deployment errors.
