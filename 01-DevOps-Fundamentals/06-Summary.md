# Key Takeaways

- DevOps is a culture and a set of practices.
- DevOps is not a software tool.
- Azure DevOps is a platform that helps implement DevOps practices.
- Automation reduces manual work and human errors.
- Developers and Operations teams work together throughout the software lifecycle.
- CI/CD is one of the core practices of DevOps.
- Monitoring and continuous improvement are important parts of DevOps.

# Final Thoughts

DevOps is not about learning tools.

It is about changing the way software is developed, tested, deployed, and maintained through collaboration and automation.

Understanding this foundation is important before learning Azure DevOps tools such as Repos, Pipelines, Docker, and CI/CD.
